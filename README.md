# MyIrving Propane Tank Tracker

![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)

Home Assistant custom integration that reads your propane tank data from the
Irving Energy residential account portal.

## Features

- Tank fill percentage sensor
- Last reading date
- Last delivery date and volume (litres)
- Today's price

## Installation

### HACS (custom repository)

1. Add this repository to HACS as a custom repository of type **Integration**.
2. Install **MyIrving Propane Tank Tracker**.
3. Restart Home Assistant.

## Configuration

Add the integration via Settings, Devices and Services. Enter the email and
password you use for the Irving Energy account portal.
